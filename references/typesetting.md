# จัดหน้าเอกสารไทย — รายละเอียด

สารบัญ
1. บีบอักษรให้ขอบขวาชิด
2. คำค้างท้ายบรรทัด (รายการคำจริง + วิธีถอดกฎเพิ่ม)
3. จุดตัดบรรทัด — แก้ที่ต้นทาง 3 ชั้น
4. วลีที่ห้ามตัดกลาง
5. line break กับย่อหน้า
6. ลายเซ็นและคำโปรยท้ายหน้า
7. วิธีวัดผลจริง

---

## 1. บีบอักษรให้ขอบขวาชิด

**หลัก:** คงการจัดแบบ `thaiDistribute` ไว้เสมอ แล้วบีบระยะห่างอักขระเพื่อดึงคำถัดไปขึ้นมา
ห้ามแก้ช่องไฟถ่างด้วยการเลิกจัดชิดขอบขวา (เคยทำแล้วกิ๊ฟทัก)

| ที่ | วิธีตั้ง |
|---|---|
| Word UI | แบบอักษร > ขั้นสูง > ระยะห่างอักขระ = กระชับ/ขยาย ตาม pt |
| ใน XML | `<w:spacing w:val="-14"/>` ใน `rPr` — หน่วย 1/20 pt · **ค่าลบ = บีบ** (0.7 pt = −14 · 0.5 pt = −10) |
| ในโค้ด | `thai_text.set_char_spacing(run, condense_pt)` หรือ `add_run(..., condense=0.7)` |

ขั้นที่กิ๊ฟใช้จริง: `CONDENSE_STEPS = (0.1, 0.2, 0.3, 0.5, 0.7)` — เกิน 0.7 ตาเริ่มจับได้
เกณฑ์ผ่าน: ช่องว่างเฉลี่ยระหว่างอักขระ `MAX_GAP_PT = 0.8` วัดจาก PDF ด้วย `get_text("rawdict")`

**อย่าไล่บีบจนสุด** (บทเรียน 16 ก.ย. 2569) — บีบบรรทัดบนมากจะดึงคำขึ้นไปเยอะ
บรรทัดล่างที่เหลือรอก้อนคำยาวจะยิ่งสั้นและถ่างหนักกว่าเดิม
ต้อง **ลองทุกขั้น วัดค่ารวมเดิมด้วย แล้วเลือกขั้นที่ถ่างน้อยที่สุด** — `word_fit.pick_condense`

ฟังก์ชันที่มีอยู่แล้ว: `word_fit.tighten_justified` (บีบแก้ช่องไฟ) ·
`word_fit.condense_to_fit` (บีบไม่ให้ล้นบรรทัด) · `word_fit.avoid_small_spill` (กันล้นหน้า 1-2 บรรทัด)

## 2. คำค้างท้ายบรรทัด

ถอดจากที่กิ๊ฟกด Shift+Enter **16 จุด** ในใบเห็นชอบแผนฯ สวช. (16 ก.ย. 2569)
ทุกจุดคือย้ายคำนำวลีที่ค้างท้ายบรรทัดลงไปขึ้นต้นบรรทัดใหม่พร้อมคำที่ตามมา

```
LEAD_WORDS  = เรื่อง · ให้ · เมื่อ · ที่เป็น · ตาม · มี · ต่อ · วงเงิน · แผนการ · สถาบัน · เพื่อ
LEAD_NOUNS  = วงเงิน · แผนการ · สถาบัน          (คำนาม เป็นกรรมของคำนำตัวหน้าได้ จึงติดกันเป็นทอด)
LEAD_BEFORE_NOUNS = รวม                          (ติดเฉพาะเมื่อตามด้วย LEAD_NOUNS)
TAIL_WORDS  = แห่งชาติ                           (ห้ามขึ้นต้นบรรทัด ต้องติดคำข้างหน้า)
```

กฎ: **ห้ามตัด *หลัง* คำพวกนี้ · ตัด *ก่อน* ได้ตามปกติ**
ตัวอย่างจุดที่กิ๊ฟตัดเอง: `…ให้เต็มวงเงิน / เมื่อสำนักงบประมาณ` (คำถัดไปเป็นคำเชื่อม ตัดได้)

**คำที่กิ๊ฟเองปล่อยให้ค้างได้ ไม่ต้องมัด:** และ · หรือ · ของ · ใน · ตั้งแต่
เลขหนังสือ `ว / ๗๖๐/๒๕๖๙` ขาดที่ช่องว่างปล่อยได้ (มัดแล้วบรรทัดบนถ่าง)

**"การ" ยืนเดี่ยว** ติดกริยาเหมือน "ความ" ได้ แต่ต้องเช็กขอบคำ ไม่งั้น `ดำเนินการ|เพื่อ` ติดกันหมด

### วิธีถอดกฎเพิ่มจากไฟล์ที่กิ๊ฟแก้มือ

1. ดึง `<w:br/>` ออกมาพร้อมข้อความรอบ ๆ — เห็นทุกจุดที่กิ๊ฟกดเอง
2. เทียบรอยต่อบรรทัดของ PDF สองฉบับ (ของเรากับของกิ๊ฟ)
3. **วัดว่าบรรทัดถ่างแค่ไหนเทียบกับฉบับกิ๊ฟ** ไม่ใช่แค่นับจำนวนคำค้าง
4. นับคำสุดท้ายของบรรทัดในฉบับกิ๊ฟ = คำที่กิ๊ฟ *ยอม* ให้ค้าง ใช้แยกว่าคำไหนไม่ต้องมัด

**สแกนคำท้ายบรรทัดต้องหาขอบขวาจริงของแต่ละใบก่อน** — ใบจัดสรรขอบขวาแคบกว่าใบแผนฯ
(~512 กับ ~536 pt) เคยใช้ค่าคงที่แล้วใบจัดสรรหลุดการตรวจทั้งใบ

## 3. จุดตัดบรรทัด — แก้ที่ต้นทาง 3 ชั้น

รากของปัญหาช่องไฟถ่างคือ **จุดตัดบรรทัดน้อยเกินไป** ไม่ใช่การจัดชิดขอบขวา

1. **`_NO_BREAK_BEFORE` ต้องไม่รวมสระหน้า** — เคยรวม เ แ โ ใ ไ ไว้ด้วย ทำให้คำอย่าง
   "และ" "ได้" "เป็น" "ให้" เกาะติดคำก่อนหน้าเป็นก้อนยาว 25-30 ตัว
   สระหน้าเขียนนำหน้าพยัญชนะและเป็นตัวแรกของคำอยู่แล้ว **ตัดบรรทัดหน้ามันได้**
   (แก้แล้วใน `core/thai_docx.py` มีผลทั้งรีโป) — ชุดที่ถูกคือสระบน/ล่าง/วรรณยุกต์/ไม้ยมกเท่านั้น
2. **`insert_zwsp(..., min_token=2)`** สำหรับงานที่จัดชิดขอบขวา (ปริยายของเอนจินกลาง = 4)
3. **`split_long_chunks`** ตัดก้อนที่ยาวเกิน `MAX_CHUNK = 12` ตัว
   คำประสมในพจนานุกรมอย่าง "งบประมาณรายจ่าย" เป็นคำเดียว พอไปอยู่ต้นบรรทัดจะดันบรรทัดก่อนหน้า
   ถ่าง 3-4 ซม. — ตัดเป็น `งบประมาณ|รายจ่าย` ได้ตามปกติของการเรียงพิมพ์ไทย

## 4. วลีที่ห้ามตัดกลาง (`KEEP_TOGETHER`)

**ใส่เฉพาะที่กิ๊ฟสั่งจริง — ห้ามเติมวลียาวเอง** ยิ่งมัดยาว จุดตัดยิ่งน้อย Word จะยืดอักษรจนผิดปกติ
(เคยใส่ "แผนการปฏิบัติงาน" แล้วช่องไฟพุ่งเป็น 7 pt)

| วลี | ที่มา |
|---|---|
| `ประจำปีงบประมาณ` · `ตามที่ขอทำความตกลงไปได้` | กิ๊ฟสั่งตรง 8 ก.ย. 2569 |
| `ความละเอียด` · `สงป.` | ร่างตอบ สวช. ขาดเป็น "ความ / ละเอียดแจ้งแล้ว" และ "สง / ป." |
| `แผนงาน` · `โครงการ` | เจอ "พ.ศ. 2570 แผน / งานบุคลากรภาครัฐ" ในร่างตอบ สวรส. |
| `ตัวชี้วัด` · `ก่อหนี้` · `แนวทาง` · `รวมทั้งสิ้น` | ตัวตัดคำแยกผิด — "ตัว\|ชี้\|วัด" "รวม\|ทั้งสิ้น" |

บวกกฎมัดอัตโนมัติ: `พ.ศ. <ปี>` และ `จำนวน <เลข> <หน่วย>`

---

## 5. line break กับย่อหน้า

ที่กิ๊ฟกด **Alt+Enter** ต้องเป็น `<w:br/>` ในย่อหน้าเดิม — `thai_text.line_break(paragraph)`
ถ้าเผลอขึ้นย่อหน้าใหม่จะได้ `space_before`/`space_after` กับย่อหน้าบรรทัดแรกติดมาด้วย
บรรทัดที่ตัดจะเยื้องผิดและกินที่เพิ่ม

---

## 6. ลายเซ็นและคำโปรยท้ายหน้า

**บรรทัดตำแหน่งต้องกึ่งกลางกับชื่อ** — ชื่อพิมพ์ชิดซ้ายที่ระยะคงที่ ส่วนบรรทัดตำแหน่งใต้ชื่อ
ต้องอยู่กึ่งกลางของชื่อ ความกว้างจริงรู้ได้จากการเรนเดอร์เท่านั้น → `word_fit.center_signature`

**คำโปรยท้ายหน้า** ทุกหน้าที่มีหน้าถัดไปต้องมี `/<คำแรกของหน้าถัดไป>...`
เอา 4 คำเป็นค่ากลาง → `catchword.add_catchwords`

**ห้ามให้หน้าใหม่ขึ้นต้นด้วยบรรทัดเดียวโดด ๆ** → `word_fit.avoid_short_start` (ขั้นต่ำ 3 บรรทัด)

## 7. วิธีวัดผลจริง

อย่าเชื่อว่าโค้ดถูก — เรนเดอร์แล้ววัด

```python
# แปลง .docx เป็น PDF ด้วย Word COM (instance แยก ไม่รบกวนไฟล์ที่กิ๊ฟเปิดอยู่)
# แล้ววัดด้วย PyMuPDF
import fitz
d = fitz.open(pdf)
for page in d:
    for b in page.get_text("dict")["blocks"]:
        for ln in b.get("lines", []):
            x1 = ln["bbox"][2]          # ขอบขวาของบรรทัด → ดูว่าชิดไหม
```

- **ขนาดอักษร/ตัวหนา:** `span["size"]`, `span["bbox"]` จาก `get_text("dict")`
- **ช่องไฟระหว่างอักขระ:** `get_text("rawdict")` แล้วดูระยะระหว่าง `chars`
- **จุดตัดกลางคำ:** เอาท้ายบรรทัดบน + ต้นบรรทัดล่างมาต่อกัน แล้วตัดคำด้วย pythainlp
  ถ้าความยาวของท้ายบรรทัดไม่ตรงกับขอบเขต token ใด = ตัดกลางคำ
  (ระวังผลบวกลวง: ถ้าจุดตัดเป็นช่องว่างจริงในต้นฉบับ ให้ข้าม)
- **ดูด้วยตา:** `page.get_pixmap(dpi=150)` บันทึก PNG ใน scratchpad แล้ว Read ภาพ
  ครอปจุดเล็กด้วย `clip=` ที่ dpi 200+
